## 产品形态

- **悬浮窗 = 节点树画板**（默认展开常驻，可折叠成横条）：毛玻璃节点卡片 + 茎状连线，Claude 浅色玻璃风格
- **主窗口**：项目列表 / 目标泳道（短中长期）/ 详情三栏 + 报表（分项目）+ 设置
- 头部横条：当前任务 + 番茄控制（⏸⏹）+ 折叠钮；悬停横条出今日浮层

## 拔树模型（核心手势）

- **屏幕外是土壤**：悬浮窗边缘之外即土壤；短期目标（根节点）在窗内贴出土侧边缘，中长期埋在土里（半透明 0.22 剪影 + 土线小鼓包提示）
- **拖拽方向 = 出土方向，树朝向 = 土壤方向**：向上拽 = 根在下、枝叶垂向下方土壤。四方向可切（设置项），默认**向下**
- **链条连续**：出土的和埋着的同一朝向，绝不翻转；**根随出土深度向屏内迁移**（根位 = 土线内侧 max(90px, 最深出土深度×GAP+50px)）
- **重力物理**：手驱动 FOLLOW 0.4 积分 + 土壤回吸 GRAVITY 2.2px/帧；**峰值拔力**（猛拽冲线算数）；**拉力消耗**（出土一个扣一份埋深，一拉一个）；seq 父节点未出土子节点不动
- **松手回弹**：easeOutBack 380ms；末端滞后甩动（按 BFS 深度 1/(1+d×0.25)）；枝干随拖拽横向速度弯曲（藤蔓感）
- **拔的单位 = 树**（seq 连通组件），不是项目；未连接的独立节点不动

## 手势词汇表（最终版）

| 手势 | 效果 |
|---|---|
| 普通按住节点拖 | **只移动该节点**相对位置（位置持久化） |
| 悬停节点 → 按住 ⇄ 把手拖 | **拔树** |
| 悬停节点 | 上排 HUD：＋新增独立节点 / 🗑删除 / ⇄拔树（根节点多 ↺单树重置）；下排**叶子** = 任务 |
| 叶子（≤2 字关键字，最多 6 + "+N"） | 点击 → 任务详情 + 任务级操作：**▶番茄（绑定该任务）** / ✓完成 / 🗑删除 |
| 悬停出挂点小圆点，拖到另一节点 | 建立顺序关联（一出多，同对不重复） |
| 双击连线 | 顺序（项目色茎）↔ 引用（细灰虚线）切换 |
| 节点/叶子/按钮 = 同一悬停上下文 | 180ms 宽限，拖动时 HUD 全部隐藏 |
| Esc / 点空白 | 关闭详情/输入 |

## 节点与连线视觉

- **节点**：半透明毛玻璃卡片（62% 白 + blur），主体只有阶段名（衬线）；右侧小卫星：期限 tag（短橙/中蓝/长灰含日期）→ 迷你进度条 → done/total → 红点任务数（项目色 badge）；全完成绿色态
- **连线（茎）**：多层光滑曲线叠加锥度（根粗梢细 3→0.8px），色彩渐淡，入点消融小圆点；顺序线项目色；跨界边在土线弯折（地上实线、地下虚线）；悬停节点时相连线加粗加亮、其余降 30%
- **出土动画**：节点从土里位置滑入槽位（0.45s 过冲）+ 阈值预热（拔力 >65% 时屏幕边界发光）

## 数据模型增量

- **Edge 成为一等实体**：`{ from: Goal, to: Goal, type: sequence | reference }`，持久化；拓扑（入度 0=根、BFS 深度）由 Edge 计算
- 节点手动位置（cx/cy）、出土状态（revealed）、拖拽方向，均需持久化（SwiftData/UserDefaults）
- 番茄记录绑定 Task（TimeEntry.task 已有）；结束确认勾掉发起的那条任务

## 布局几何

- 矩形 = 悬浮窗 bounds；root/槽位/土壤线由窗框计算；同层兄弟以父节点 cross 为中心扇开（110px 间距，含哈希抖动）
- 孤立节点（无 seq 连接）排在根层旁边
