# Twig 核心交互设计 v2（拔树模型）

日期：2026-07-31
状态：原型迭代中（HTML 原型 v6，待用户验收后做减法）
原型：`~/.superpowers/brainstorm/*/content/prototype-v5.html`（经可视化伴侣服务）

## 核心隐喻

**屏幕外是土壤。** 中长期目标埋在土里，短期目标露在外面。拔树 = 把未来从土壤里拽出来看；松手 = 树弹回原位，但被拽出土的节点留在屏上。

## 形态

- **悬浮窗默认展开**（v1 的"横条收起态"被否决）：头部横条（当前任务 + 番茄控制 + 折叠钮 ▾）+ 节点树常显
- **节点 = 目标（goal）**，矩形玻璃信息卡（~150px 宽）：标题 + 一行元信息（日期 · 期限 · 剩余任务数）+ 右上角任务进度环
- 默认只有短期目标节点在屏内；中期/长期以暗淡剪影埋在"土壤"（屏幕边缘渐变带）下
- 枝干：贝塞尔曲线，两端焊在节点上，按深度变细；跨界边在**土壤交界点弯折**——地上实线、地下虚线
- 差异色彩：每个项目一个颜色（左色条 + 连线 + 进度环）

## 手势词汇表

| 手势 | 效果 |
|---|---|
| 按住节点沿主轴拖拽 | **拔树**：整树刚性跟出（阻力 0.55），末端按深度滞后甩动（植物弯杆感）；松手 easeOutBack 回弹 |
| 拔过某节点的"埋土深度" | 该节点**出土**：弹入屏内槽位（逐个 stagger），留在屏上 |
| 悬停节点 | 进入**悬停上下文**（节点 + 功能按钮 = 一个 state，180ms 宽限才退出）：浮出图标按钮 ＋新增分支 / ▶开始番茄 / 🗑删除 / ✥移动 |
| 按住 ✥ 拖 | **移动节点**（唯一改变节点位置的方式；普通拖拽 = 拔树，不误移） |
| 点击节点 | 展开**详情面板**（任务勾选/删除、底部加任务、双击改目标名/日期/任务名） |
| Esc | 关闭详情/新增输入/功能按钮 |
| 头部 ▾ | 折叠成一条（横条 + 虚线末梢圆，v1 的收起态降级为可选） |
| 悬停头部横条 | 今日任务浮层 |

## 专注联动

- 节点 ▶ → 番茄开始：节点脉冲光环，横条显示倒计时 + ⏸暂停/继续 + ⏹停止
- 番茄结束 → 横条内联确认「完成了吗？ ✓ / ↻」—— ✓ 勾掉该目标第一个未完成任务
- 目标全部任务完成 → 节点绿色完成态

## 布局与方向

- 主轴四方向（右/下/左/上），**默认向上**；已揭示节点从锚点沿主轴等距排（间距带确定性抖动），未揭示的在边界外 120px 起
- 自然松散感：每个节点按 id 哈希有交叉轴抖动（±22px）和间距变化（0.88~1.12×）
- 拖拽物理：跟随系数 1/(1+深度×0.25)（根先动梢后摆）；回弹 easeOutBack 380ms；枝干弯度随拖拽幅度增大（≤40px）

## 持久化（原型行为，Swift 版映射）

- 揭示状态、✥移动位置、任务勾选、方向选择都持久化（原型用 localStorage；Swift 版用 SwiftData/UserDefaults）

## 可调参数（手感迭代入口）

| 参数 | 当前值 | 含义 |
|---|---|---|
| RESIST | 0.55 | 拖拽阻力（树跟随比例） |
| 滞后系数 | 0.25 | 末端甩动强度 |
| 回弹时长 | 380ms | easeOutBack |
| 出土阈值 | 埋深 + 40px | 拔多远节点出土 |
| GAP | 190px | 枝距 |
| 悬停宽限 | 180ms | 功能区防抖 |
