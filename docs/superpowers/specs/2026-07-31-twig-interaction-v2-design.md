## 核心隐喻

**中央四边形 = 屏幕，矩形外 = 土壤。** 屏幕矩形按视口真正居中（76% 宽 × 80% 高），长期目标埋在矩形外的土壤里，短期目标（根节点）在矩形内。**拔树 = 克服重力把未来从土里拽出来；松手 = 树回弹归位，被拽出土的留下。**

## 朝向约定（重要）

**按钮方向 = 拖拽/出土方向，树的朝向相反**：向上拽 → 根在上（贴横条）、枝叶朝下、深层埋在下边界土壤；向右拽 → 根在右、枝叶朝左、埋左边界。依此类推。根节点锚点：up=矩形 35% 高度、down=65%、left=40% 宽、right=60% 宽（不贴边）。

## 重力与拉力模型

- 拖拽位移不是 1:1 跟随：手驱动（FOLLOW 0.28 积分趋近目标）与**土壤回吸**（GRAVITY 2.2px/帧 + 2% 衰减）对抗——**停手树就往土里滑**
- **峰值拔力**：猛拽冲过阈值就算数（peakRaw 记录最大值），重力拽回去不反悔
- **拉力消耗**：每出土一个节点，从峰值里扣掉它的埋深（consumed）——**一次拖拽 ≈ 出土一个**，想要下一个必须重新发力
- **顺序约束**：seq 父节点没出土，子节点不会被拽动
- 松手：easeOutBack 回弹（380ms 过冲），pullState 在末帧才清空（防瞬移）

## 布局

- **拓扑布局**：seq 入度 0 = 根（贴锚点），深度沿顺序线递增；槽位从锚点等距排（带哈希抖动），主轴排不下往交叉轴换行；`sanitizeReveal` 保证祖先先于子孙出土
- **出土生长动画**：节点从土里位置带过渡滑入槽位（.45s 过冲曲线）；闲置时槽位变化全部 CSS 过渡（拖拽/回弹期间关闭防打架）
- **出土渐变**：接近出土时节点 0.22→0.85 渐显；**阈值预热**：拔力超过埋深 65% 时屏幕边界发光

## 手势词汇表

| 手势 | 效果 |
|---|---|
| 按住节点沿出土方向拖拽 | 拔树（重力对抗，末端按 BFS 深度滞后甩动） |
| 松手 | 整树回弹归位，出土的留下 |
| 悬停节点 | 悬停上下文（节点+功能区一体，180ms 宽限）：＋新增独立节点 / ▶番茄 / 🗑删除 / ✥移动 + 出挂点圆点 |
| 从出挂点拉线到另一节点 | 建立顺序关联（一个节点只留一条出向 seq） |
| 双击连线 | 顺序（彩色带箭头）↔ 引用（细灰虚线）切换 |
| 点击节点 | 详情面板（夹取在矩形内）：任务勾选/删除/底部添加、双击改目标名/日期/任务名 |
| Esc | 关闭详情/输入/按钮 |
| 头部 ▾ | 折叠成横条 + 虚线末梢 |

## 专注联动

节点 ▶ → 番茄：节点脉冲光环、横条倒计时 + ⏸/⏹；结束内联确认「完成了吗 ✓/↻」；进度环；全完成绿色态。

## 持久化

揭示状态、✥移动位置、连线类型、任务勾选、方向（localStorage；Swift 版映射 SwiftData/UserDefaults）。存档版本键随结构升级作废旧档。

## 可调参数

| 参数 | 值 | 含义 |
|---|---|---|
| FOLLOW | 0.28 | 手驱动强度 |
| GRAVITY | 2.2 + 2% | 土壤回吸 |
| 出土阈值 | 埋深 + 40 | 峰值超过即出土 |
| 埋深间距 | 160 + j×247 | 相邻节点埋深差 |
| 回弹 | easeOutBack 380ms | 松手动画 |
| GAP | 190px | 枝距 |
| 滞后系数 | 0.25 | 末端甩动（按 BFS 深度） |
